# Contributing to the Restaurant Service

We welcome contributions! Please follow these guidelines.

## Code Style

- Please run `go fmt` on your code before committing.
- We follow standard Go conventions.

## Commit Messages

Please use the [Conventional Commits](https://www.conventionalcommits.org/) format.
- `feat:` for new features.
- `fix:` for bug fixes.
- `docs:` for documentation changes.
- `chore:` for build process or tooling changes.

## Submitting a Pull Request

1. Fork the repository.
2. Create a new branch for your feature (`git checkout -b feat/my-new-feature`).
3. Make your changes.
4. Add and commit your changes with a conventional commit message.
5. Push to your branch (`git push origin feat/my-new-feature`).
6. Create a new Pull Request.
